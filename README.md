# 🎲 Jogo de Adivinhação em JavaScript

> Um jogo interativo e divertido onde o objetivo é adivinhar um número secreto gerado aleatoriamente dentro de um intervalo estipulado, contando com feedback visual a cada tentativa.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco no aprimoramento da lógica de programação utilizando **JavaScript moderno (ES6+)**. A aplicação manipula o DOM dinamicamente para interagir com o usuário, validar palpites, contar tentativas e reiniciar o jogo de forma fluida.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica da interface do jogo.
* **CSS3:** Estilização visual, layout centralizado e design responsivo.
* **JavaScript (ES6+):** Lógica principal, geração de números aleatórios (`Math.random`), validações e manipulação do DOM.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Geração aleatória:** Um número secreto é gerado de forma dinâmica a cada nova partida.
* **Feedback interativo:** O sistema avisa se o número digitado é maior ou menor que o número secreto.
* **Contador de tentativas:** Acompanha quantas tentativas o jogador levou para acertar.
* **Botão de Reiniciar:** Permite jogar novamente de forma rápida após acertar o palpite.
